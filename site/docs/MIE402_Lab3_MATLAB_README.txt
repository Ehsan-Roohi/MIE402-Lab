MIE 402 Lab 3 MATLAB files — Fall 2026
1. Keep all .m files in one MATLAB folder. Install the bundled PendulumMotionAnalyzer_V4.mltbx.
2. Run Test_Lab3_Model.m once. It checks the model and coordinate convention.
3. Run Run_Lab3_Simulation.m after replacing illustrative masses and lengths with measured values.
4. In Pendulum Motion Analyzer V4, select Double Pendulum, track both bobs, Save Results.
5. Run Run_Lab3_ExpData_Analysis.m and choose that ExpData MAT file. Repeat for each trial.
Do not click Run in MIE402_Lab3_RHS.m or MIE402_Lab3_Energy.m: they are functions needing inputs.
The experiment script does not use sineFit.m. Record original capture fps, not MP4 playback fps.
