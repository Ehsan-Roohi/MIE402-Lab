Four release cases

Record one small nonzero aligned-link release and at least three larger-angle releases. Include two similar but distinct starts; document the actual angles rather than only the intended angles. Measure both bar masses, lumped bob/hardware masses, and pivot-to-center lengths. Keep the camera capture frame rate and calibration distance with each trial.

From camera to analysis

  1. Set 1280 × 1024 and nominal 1000 capture frames/s or document the actual camera setting. Frame the entire motion and focus both bobs.
  2. Save the raw H.264 MP4. The MP4 playback rate is not the capture rate.
  3. In Pendulum Motion Analyzer V4 select Double Pendulum, enter capture fps, calibrate the mark separation, locate pivot and both centers, run Quick Review, then analyze all frames.
  4. Save the MAT file. ExpData columns are time (s), x1 (mm), y1 (mm), x2 (mm), y2 (mm). The app reports right-positive x and up-positive y relative to the pivot.
  5. Run Run_Lab3_ExpData_Analysis.m. For each trial check both absolute angle traces, angular velocities, and spectra. Show one full trial set to your GTA before leaving.

Angles from the downward vertical: theta1 = unwrap(atan2(x1, −y1)) and theta2 = unwrap(atan2(x2−x1, −(y2−y1))). Both are approximately zero when both links hang down. The second is the lower link's absolute angle, not theta2−theta1.

Run the scripts, not the helper functions. First run Test_Lab3_Model.m, then Run_Lab3_Simulation.m with your measured parameters, and Run_Lab3_ExpData_Analysis.m on each saved MAT file. Do not click Run inside MIE402_Lab3_RHS.m or MIE402_Lab3_Energy.m; they need input arguments. Lab 3 does not use sineFit.m.

The undamped model is a baseline. Measured amplitude loss can reflect pivot friction and air drag. A short trace can show sensitivity, but is not alone proof of chaos. Combined Labs 2–3 report: tentatively due November 2; check Canvas.
